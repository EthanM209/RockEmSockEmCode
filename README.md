# RockEmSockEmCode
Code for Rock Em Sock Em project. Project uses 10 servo motors to move figures around an arena and make them punch each other. The board 1 and 2 files are for the project are ment to be used if you only have access to one controller. When testing and designing this project I only had one Xbox controller that was compatible with the ESP32 I used. To get around this one ESP 32 takes the inputs from the controller and uses ESP now to send them to the other. 2ControllerCode is the code for both ESP 32s if you have access to both controllers. 

This project used 4 micro 180 degree servos, 2 180 degree servos, 4 360 degree servos, 2 XIAO ESP 32 C3s, A laser cut frame, and 3D printed parts.
